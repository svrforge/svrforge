# Contributing

Thanks for supporting this original open-source learning tool.

1. Describe an issue with safe, synthetic reproduction data.
2. Keep changes focused and maintain the local-only, read-only behavior.
3. Run `python -m unittest discover -s tests -v` from this tool's directory.
4. Include unit tests for new rules and update the README for changed behavior.
5. Do not submit cloud credentials, customer data or other confidential material.

By contributing, you agree to respectful, constructive collaboration. See the parent project's [Code of Conduct](https://github.com/svrforge/svrforge/blob/main/CODE_OF_CONDUCT.md).
