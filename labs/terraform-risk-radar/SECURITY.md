# Security and limitations

This is a local, read-only educational analyzer. It is **not** a production scanner, comprehensive parser, compliance certification or a substitute for professional review.

Do not publish real infrastructure manifests, cloud credentials, secret values, proprietary code or customer data. Use only synthetic examples when opening public issues.

For a sensitive vulnerability, prefer [private vulnerability reporting](https://github.com/devopsvikki/devopsvikki/security/advisories/new) when available.

Only the latest main-branch version is maintained; no guaranteed support timeline.
