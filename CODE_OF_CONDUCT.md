# Code of Conduct

This is a small, community-focused open-source engineering project.

Be respectful and professional. Welcome different experience levels and perspectives. Provide actionable feedback about ideas and code, not personal attacks. Harassment, discrimination, threats, doxxing and sharing confidential information are not acceptable.

For routine concerns, open a repository issue. For private or sensitive concerns, use GitHub's private reporting feature where available. Maintainers may moderate or remove contributions that violate these expectations.

This policy applies to project discussions, issues and pull requests.
